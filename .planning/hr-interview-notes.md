## Ключевые решения

- Профессия из штатного файла = каноническая (не из файла смен)
- Разряд хранится в отдельном поле `professions.grade`
- ФИО разбивается: last_name / first_name / middle_name
- Инвалидность: is_disabled + disability_group (1/2/3) + disability_notes (ограничения)
- Парковщики: `participates_in_stroyevaya = false`
- Мобилизован ≠ СВО (юридически разные категории, оба хранятся через svo_type)
- Испытательный срок: probation_start + probation_end (не просто флаг)
- Бригада №1 в файле смен = просто "рабочий", не структурная единица
- Водители: на паузе, вернуться при разработке страницы гл. механика
