Create `src/components/hr/HRTableView.tsx` as a `'use client'` component.

**Props interface:**
```typescript
interface Props {
  employees: EnrichedEmployee[]
  canEdit: boolean
  currentUserId: string
  onNameClick: (userId: string) => void
  onRefresh: () => void
}
```

**Component structure:** `HRTableView` (outer table) + `HRTableRow` (inner, one per employee — manages its own popup and optimistic status state).

**HRTableRow internal state:**
- `localStatus: EmployeeStatusType` — optimistic status, initialized from `employee.currentStatus`
- `popupOpen: boolean` — whether the status popup is visible
- `pendingStatus: EmployeeStatusType | null` — status selected in popup, waiting for reason
- `reasonText: string` — reason input value
- `saving: boolean`
- `error: string | null`

**Table structure:**
```
columns: Name | Service | Status
row height: py-2.5 (≈40-44px total including border)
```

**Name column:** `<button>` with `onClick={() => onNameClick(employee.user.user_id)}` — text-sm text-white/80 hover:text-teal-300 transition-colors text-left. Truncate long names.

**Service column:** Display `SERVICE_META[serviceId]?.emoji + ' ' + serviceName` — but since `EnrichedEmployee` only has `user.service_id` (not service name), look up emoji from `SERVICE_META[user.service_id]` and display as `emoji + ' ' + serviceId` abbreviated form (e.g. "⚡ SRV-ENG"). NOTE: Pass `services: Service[]` as additional prop to resolve service names from `service_id`. Add `services: Service[]` to the Props interface. Service display: `emoji serviceName` (short). If `user.service_id` is null, show `—`.

**Status column:** Status badge chip. When `canEdit` is true — wrap in a `<button>` with `onClick={() => setPopupOpen(true)}` and `cursor-pointer hover:opacity-80 transition-opacity`. When `canEdit` is false — render as plain `<span>`, not clickable.

**StatusPopup:**
- Rendered in the same table cell as a sibling of the badge, inside a `relative` wrapper div
- Positioned with `absolute z-50 top-full left-0 mt-1` — drops down below the badge
- Background: `bg-slate-900 border border-white/10 rounded-xl shadow-2xl` — dark glass popup
- Width: `w-52` (208px) — compact but readable
- Structure:
  ```
  <div class="p-2 space-y-0.5">
    Group 1 header: <div class="text-xs text-white/30 px-2 py-1">Ежедневные</div>
    DAILY_STATUSES items
    <div class="border-t border-white/10 my-1" />  <!-- divider -->
    Group 2 header: <div class="text-xs text-white/30 px-2 py-1">Расширенные</div>
    EXTENDED_STATUSES items
  </div>
  ```
- Each status item: `<button>` with `flex items-center gap-2 w-full px-2 py-1.5 rounded-lg text-xs hover:bg-white/10 transition-colors`
  - Left: checkmark `✓` (visible when `localStatus === status`, hidden otherwise — use `opacity-0` to preserve spacing)
  - Right: colored badge chip (matching the status's `cfg.color` and `cfg.bg`)
  - Status label text

**Popup outside-click close:** Use `useEffect` + `useRef` on the popup container. Add `document.addEventListener('mousedown', handler)` when `popupOpen` is true. Remove on cleanup. If click is outside the ref element, call `setPopupOpen(false)` and clear pending state.

**Status selection flow (same logic as EmployeeCard):**
1. User clicks status in popup → if same as current, close popup → if Na_rabote: save immediately (no reason needed) → otherwise: show reason input inside popup
2. Reason input appears inside popup below the status list (replace the list with the reason UI, or show below — choose: REPLACE the status list with reason input for clean UX)
3. Reason UI: text input (`placeholder="Причина (необязательно)"`) + confirm button (✓) + cancel button (✕)
4. Confirm: if `reasonText.trim()` non-empty, call `setEmployeeStatus(userId, pendingStatus, today, today, reasonText.trim(), currentUserId)`. If empty, skip the reason call.
5. On confirm: close popup, clear pending state
6. On cancel: close popup, rollback `localStatus` to original (the save already happened in step 1)

**Optimistic update + rollback (identical to EmployeeCard pattern):**
```
const prevStatus = localStatus
setLocalStatus(newStatus)   // optimistic
setSaving(true)
const result = await setEmployeeStatus(userId, newStatus, today, today, null, currentUserId)
setSaving(false)
if (!result) {
  setLocalStatus(prevStatus)   // rollback
  setError('Не удалось сохранить статус')
} else {
  onRefresh()
}
```

</tr>
