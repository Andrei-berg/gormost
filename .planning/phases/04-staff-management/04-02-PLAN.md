**Section 2 — Insert all professions:**

- 'Инженер 1 категория' → name='Инженер', grade='1 категория', category='ИТР'
- Skip the `<Объект не найден>` entry — do not insert it as a profession
- Include all distinct (name, COALESCE(grade,'')) combinations found in the roster

Section B — employee_positions INSERT (use DO NOTHING on conflict since the partial unique index will fire):
For each employee (except the `<Объект не найден>` one), insert a positions row using a subquery to look up profession_id:

```sql
INSERT INTO employee_positions (user_id, profession_id, started_at, change_reason)
SELECT
  u.user_id,
  p.id,
  u.date_hired,
  'прием'
FROM users u
JOIN professions p ON (p.name, COALESCE(p.grade, '')) = ('Пескоструйщик', '4 разряд')
WHERE u.tab_number = '0000-00780'
ON CONFLICT DO NOTHING;
```

Use this subquery pattern for all employees. Group them if they share a profession to reduce repetition.

Section C — employee_assignments INSERT:
For each employee, insert an assignments row using:
- schedule_id via subquery: `SELECT id FROM schedules WHERE code = 'сутки/3'`
- shift_num from roster: 1, 2, 3, or 4 (NULL for non-сутки/3 schedules)
- foreman_name from roster `foreman` field (NULL if empty)
- shift_reference_date based on shift_num:
  - shift 1 → '2026-03-07'
  - shift 2 → '2026-03-08'
  - shift 3 → '2026-03-05'
  - shift 4 → '2026-03-06'
  - NULL for non-сутки/3 schedules (shift_num is NULL)
- rotation_group based on schedule variant normalization:
  - '15/15 (1)' → '1'
  - '15/15 (2)' → '2'
  - '15/15 (2,1)' → '2_1'
  - '15/15(2)' → '2'
  - '15/15' (bare) → '1'
  - All others → NULL
- started_at = date_hired
- is_driver = false (driver handling deferred per CONTEXT.md)

```sql
INSERT INTO employee_assignments (user_id, schedule_id, shift_num, foreman_name, shift_reference_date, rotation_group, is_driver, started_at)
SELECT
  u.user_id,
  s.id,
  1,           -- shift_num
  'Чекин А.В.',
  '2026-03-07',
  NULL,         -- rotation_group
  false,        -- is_driver
  u.date_hired
FROM users u
CROSS JOIN (SELECT id FROM schedules WHERE code = 'сутки/3') s
WHERE u.tab_number = '0000-00780'
ON CONFLICT DO NOTHING;
```
