<objective>
Ship the alias manager: a new `/admin` → «Синонимы» tab where an ADMIN searches, adds, re-weights
and deletes the surface forms that teach the resolver irregular Russian — with the D-13 soft
collision warning. Then collapse the project's two normalizers into one by re-pointing the journal
`norm` at `src/lib/kb/normalize.ts`.

Purpose: the alias table is the resolver's primary mechanism for the forms no stemmer reaches
(«БК», «ЭВ №3», «тт №3 КТР»); fuzzy matching is the fallback. Without a manager the table can only
grow by migration, and Phase 13's correction loop has no human-facing counterpart.

Output: `AliasManagerTab.tsx` wired into the admin tab router, and one canonical normalizer.
</objective>

|----------|-------------|
| ADMIN free-text surface input -> `entity_aliases` | Arbitrary text is stored verbatim in `surface_raw` and rendered back in the list |
