<objective>
Replace the tracer's pass-through `stem()` with a vendored Russian Porter/Snowball stemmer, and
lock the swap point behind the D-12a fixture gate so any future lemmatizer must earn its place.
Then close the D-12 spike with a hard timebox and an explicit dependency sign-off.

Purpose: Russian declensions are the reason naive matching fails on «на Лефортовском тоннеле»
(RESEARCH Pitfall 2). The stemmer is the fuzzy layer's morphological floor — Plan 08-05's scoring
is only meaningful once tokens reduce to stable stems.

Output: a zero-dependency `stem.ts` validated against the official Snowball sample vocabulary, a
mandatory `lemma-cases.ru.ts` gate, and a closed spike decision.
</objective>

    Write `stem.test.ts` FIRST as a table-driven test over an inlined subset of the official
    snowballstem.org Russian sample vocabulary (at least 60 word/stem pairs chosen to exercise each
    step), red before implementation:
    - Perfective gerund endings are removed (step 1, both the `в`/`вши`/`вшись` group after
      `а`/`я` and the unconditional group).
    - Reflexive `ся`/`сь` is removed before the adjectival/verb/noun attempt.
    - Adjectival, participle, verb and noun ending groups are removed only within RV.
    - Terminal `и` is removed (step 2).
    - Derivational `ость`/`ост` is removed only when it sits in R2 (step 3).
    - Superlative `ейш`/`ейше`, doubled `нн` reduction, and terminal soft sign are handled (step 4).
    - Words with `ё` already folded to `е` by `normalize` stem identically to their `е` spelling.
    - A one-letter token and an empty token are returned unchanged (no throw, no index error).
    - A Latin or numeric token is returned unchanged.
  </behavior>

    replacing the tracer's pass-through body. Keep the exported signature
    `stem(token: string): string` exactly as it is — every caller stays untouched.

    the four steps in order with regex ending groups scoped to the correct region. Keep each ending
    group as a named module-level constant so the test failure message and a reviewer can map a
    failing pair back to a step. Zero imports.

    File header cites `snowballstem.org/algorithms/russian/stemmer.html` as the source of truth,
