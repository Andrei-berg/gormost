## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Russian free text -> preprocessing | Arbitrary untrusted input (pasted dictation in Phase 11, spreadsheet cells in Phase 9) reaches these pure functions |
| Index build time vs query time | Two call sites of the same function; divergence silently breaks every alias |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-08 | Tampering (data integrity) | Divergent preprocessing between index build and query | high | mitigate | Single exported `preprocess` with no options or variants; `preprocess.test.ts` asserts identical output for the four consumer kinds and that `normalized` is exactly `normalize(expandAbbreviations(input))` |
| T-08-09 | Denial of service | Catastrophic regex backtracking on a long pasted phrase | medium | mitigate | Rules are linear character-class replacements, not nested quantifiers; the abbreviation matcher is built from literal dictionary keys with boundary anchors rather than hand-written alternation |
| T-08-10 | Tampering | Abbreviation expansion inside a longer word corrupting a real name | medium | mitigate | Token-boundary matching with longest-key-first ordering; a test asserts a substring occurrence is left unchanged |
| T-08-11 | Information disclosure | — | low | accept | No I/O, no logging, no secrets in these modules; input is echoed only into the return value |
| T-08-03 | Information disclosure | `src/lib/kb/` bundled to the browser | medium | mitigate | `purity.test.ts` (Plan 08-01) already fails the build on a server or API import |
