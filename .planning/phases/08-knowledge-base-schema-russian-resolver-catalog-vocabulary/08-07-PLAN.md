## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Migration file -> live production-facing database | The seed writes real rows into a database backing a shared demo URL |
| Seeded `surface_norm` -> resolver index key | A value computed by anything other than the shipped pipeline silently disables the alias |
| Human SQL Editor session -> schema | The only path by which schema changes reach the database in this project |
